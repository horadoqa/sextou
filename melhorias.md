# Melhorias

Identidade Visual

Cores: verde profundo 
#0F3D2E como base (não neon sobre preto), verde-musgo 
#3F6F52 para apoio, verde-sinal 
#8FE3B0 reservado a destaques tipo "aprovado", dourado 
#C99A44 como contraponto de sofisticação, marfim 
#F3EFE6 e tinta 
#12201A para texto.

Tipografia: Newsreader itálica (serifada editorial) para títulos/wordmark — dá caráter humano e foge do sans genérico — combinada com JetBrains Mono de verdade (a mesma de terminal) para status, tags e código, e Manrope para o corpo de texto.

Uso: aplicável tanto em fundo escuro quanto claro, com o verde-sinal funcionando quase como um "PASS" de relatório de teste, aparecendo pouco de propósito.
